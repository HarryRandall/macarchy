# Macarchy Settings

A native macOS control panel for the Macarchy desktop stack — yabai, borders,
sketchybar, skhd, and the `theme-switch` theming engine.

Replaces hand-editing dotfiles (and the Raycast theme-switcher extension) with a
menu bar picker and a real settings window.

Personal project. Not published, not notarized, not for distribution.

- **[CONTRIBUTING.md](CONTRIBUTING.md)** — rules for working in this repo.
- **[Docs/PLAN.md](Docs/PLAN.md)** — architecture, current state, migration phases, traps.

## Status

In use. Seven panes working — Themes, Borders, Menu Bar, Layout, Rules,
Shortcuts, Advanced. `bordersrc`, `yabairc` and `sketchybarrc` are generated by
the app. `theme-switch` is down to 947 lines, with the Ghostty surface ported.

```sh
./Scripts/run.sh      # build, bundle, sign, install, relaunch
./Scripts/doctor.sh   # 36 machine assertions — the gate
./Scripts/test.sh     # 20 unit tests
```

## Requirements

- macOS 27
- Xcode 27 command line tools, license accepted (`sudo xcodebuild -license`)
- Existing Macarchy stack: yabai, borders, sketchybar, skhd, `~/.local/bin/theme-switch`
